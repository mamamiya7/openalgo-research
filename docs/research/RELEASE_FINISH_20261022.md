# Finish the supported preview.8 release

Feature scope is frozen on 22 October 2026. The supported product is one native
OpenAlgo distribution for NSE cash-equity CSV/Chartink signal portfolios:
Historify price reuse, fixed backtests, bounded VectorBT/Optuna automatic research,
chronological checks, execution/portfolio constraints, saved findings, reports,
native trade charts and exact setup reuse. Optional Nautilus calculations keep
their separately qualified profile; they do not inherit v16 automatic research.

## Finite completion gates

1. Fix the actual frontend dependency advisory and compatibility-run timeouts
   without dropping tests or weakening evidence checks.
2. Measure the already identified JSON evidence cost. Any optimization must keep
   old hashes, byte limits, reports and numerical results exact, with bounded
   memory and streaming fallback. No larger search budget is part of this release.
3. Check the current import → essential intent → research → inspect → named save
   → reopen/reuse loop, with honest progress, no-edge/unsupported outcomes and
   interrupted recovery. Keep advanced controls optional. Distinguish browser
   observations, service fixtures and full native calculation evidence.
4. Build a fresh ZIP with matching source identity, manifest and checksums.
   Verify private-data exclusions, installation/reinstallation and synthetic
   populated update/rollback. Record supported-platform checks for this candidate.
5. Reconcile installation guides, release notes and public links, then install
   the qualified changes locally and push the reviewed source. A source push is
   not a published ZIP; change public download links only after that ZIP exists.

Existing scoped qualification remains valid for its recorded source: v16 has
400 backend/276 frontend checks, genuine native no-edge and positive-control
programmes, exact recovery and saved allocation replay. This does not claim
general false-discovery control, universal optimality or future profitability.
Local receipts stay under ignored `.agent-native/release-finish-20261022/`.

## After release

Broader independent calibration, more allocation/rebalancing, volume/intraday
methods, learned regimes, sector/factor metadata, more assets/venues, full scanner
rule reproduction and Chrome Web Store publication are future increments. They
must not keep reopening this release's scope. Ordinary bug fixes remain in scope.
