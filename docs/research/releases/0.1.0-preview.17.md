# OpenAlgo Research 0.1.0-preview.17

Faster cached stock preparation on OpenAlgo 2.0.2.7. Features, search budgets,
financial versions, dependencies and installation steps are unchanged.

## Changes

Group recovery saves for up to 16 fully cached stock warmup records. Every
candle, receipt, calendar and record still passes its existing checks; symbol
progress stays visible. Native checkpoints before broker work and after each
response stay immediate. No extra broker concurrency or second price database.

A stopped, uncommitted cache group may repeat up to 16 local stock checks on
resume. Existing saved evidence and recorded broker responses remain intact.

## Qualification

61 focused checks passed, covering native cache equality, all visible symbol
counts, interruption/resume, broker boundaries, malformed evidence, resources and
older checkpoint recovery. A short native preparation comparison with three real
cached stocks plus NIFTY took **9.601 →6.237s (35.0% less)**; storage scans fell
47 →22 and final evidence/checkpoint hashes matched. A 17-stock test reduced
stock-wrapper recovery publications 69 →4 with identical final evidence. A second
short pair with reused immutable data and changed settings measured **4.433 →2.247s
(49.3% less)**, strict scans 34 →12, again with identical final evidence. These
are individual matched pairs, not statistical runtime guarantees.

These are preparation measurements, not a new whole-run or fresh-download timing.
The last complete cached real-sample optimisation remains **6m50.091s** on preview.15.
No broker requests or live orders were used for this patch. No platform/install
contracts changed; the full installation matrix was not repeated. Validated
frontend assets are reused after source and asset checks.
See [verification](../VERIFICATION.md#cached-stock-preparation--22-october-2026).

## Install and update

Download the complete
[preview.17 ZIP](https://github.com/mamamiya7/openalgo-research/releases/download/research-v0.1.0-preview.17/openalgo-research-0.1.0-preview.17.zip)
and verify against `SHA256SUMS`. Extract all files and run **Setup.cmd** on Windows
or **setup-research.sh** on Linux. Do not download Setup.cmd alone.

Existing users: stop the app and worker, back up the application/data, preserve
existing data paths, update files and restart. See
[update instructions](../RUNTIME.md#preserve-data-during-updates). No new migrations.
