# OpenAlgo Research 0.1.0-preview.22

This frozen-feature patch removes repeated hashing, copying and preparation and
avoids first-use compilation of report dispatch loops. The configured search
maximum remains 408 proposals and 512 accounts; full validation, financial
semantics, platform 2.0.2.9, charts 2.6.7 and dependency pins are unchanged.

## Corrections

- Validate and detach canonical evidence once, then reuse its exact owned bytes
  for native checkpoint publication. Ownership is thread-scoped and bounded;
  custom callbacks and unsupported layouts retain the ordinary fresh path.
- Admit exact native float64 scalars without a failed encoding pass. Preserve
  exact canonical bytes and all type, finite, cycle, node, depth and byte guards.
- Fuse constraint snapshot, size admission and successful-result hashing. All
  current-account calendar, opportunity, entry, fill and constraint checks remain.
- Reuse private bounded prepared stock/market views and exact causal feature
  decisions. Copies returned to callers remain detached; custom gates disable
  reuse. Complete hypothesis and decision identities prevent cross-trial reuse.
- Avoid copies of an unused recipe field only for discarded native trial reports;
  retained selected/final reports and generic callback contracts remain complete.
- Call the exact Python bodies of native empty simulation hooks and eight outer
  report dispatch loops. Financial reducer and streak callbacks stay compiled.
  No dependency code, financial formula or global JIT setting is changed.
- Keep every trial history, fresh disk inventory, integrity verification, quota,
  path/symlink checks, durable attempt reservation and pause/ownership fence.

## Installed application measurement

The ordinary signed-in Windows application, after restart, completed the real
83-signal/six-stock CSV programme in **45.089 seconds** from job creation to
completion (**46.014 seconds** from the Optimize click). This includes preparation
of all 365 required daily execution candles, the full applicable programme,
validation and evidence publication. All required execution candles were cached;
zero were downloaded in this acceptance run.

All **272 applicable proposals, 296 accounts and 294 development histories** are
retained. Conditional extra seeds remain inapplicable after the unchanged checks;
the configured 408/512 maximum has not been reduced.

The separate exact tested backtest completed in **1.768 seconds**. The research
report analysis job completed in **1.247 seconds**. A matching tested setup was
saved, survived a browser reload and reopened its persisted report with identical
figures: 3.15% return, 4.31% maximum drawdown and 46 closed selection-period trades.
Save/navigation/operator review time is excluded from the job clocks. Existing
configuration and saved research were preserved; no orders or mode changes.

This meets the one-minute research-job target for this measured cached-data case.
It is not a timing guarantee for larger inputs, fresh broker downloads or every
machine. The first pre-final installed run took 62.598s, including three newly
available candles and report-dispatch compilation. An isolated empty-cache A/B
removed 6.517s of dispatch compilation with identical complete reports.

## Qualification

The broad qualification covered 842 passing tests and four Windows symlink
fixture skips (link creation privilege unavailable). One outdated resource fixture
also failed on unchanged public source; it now supplies the required sealed
execution receipt and checks closure of all 300 success/cancel/error owners.
Post-format focused checks passed (137 tests). Final report-dispatch qualification
passed 53 tests, with five optional Nautilus provider skips in that focused
command. These overlapping suites are not added into an inflated total.

Coverage includes exact daily/minute/empty report parity (all 121 metrics), exact
canonical bytes, mutation isolation, malformed evidence, bounded ownership and
cache lifetime, unsupported fallback, native financial callbacks, cancellation,
pause/crash behavior and retained histories. Changed Python source passes Ruff
and source distribution compatibility checks. Private inputs, results, runtime
stores and screenshots are excluded from the public package.
