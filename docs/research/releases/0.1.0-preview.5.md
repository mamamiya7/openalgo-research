# OpenAlgo Research 0.1.0-preview.5

One download now includes the current OpenAlgo Research interface, guided setup,
and a launcher that starts the app and calculation worker together.

## Install

1. Download **openalgo-research-0.1.0-preview.5.zip** from
   [this release](https://github.com/mamamiya7/openalgo-research/releases/tag/research-v0.1.0-preview.5)
   and extract the whole ZIP into a permanent folder.
2. On Windows x64, double-click **Setup.cmd** and choose your broker. It installs
   private Python 3.12 and the locked dependencies. Internet is needed initially;
   Python, Git and Node.js do not need to be installed separately.
3. Create your OpenAlgo account in the browser, enter your broker app credentials
   in **Profile → Broker Credentials**, connect the broker, then open
   **Tools → Backtest & Optimize**. Start with a small dated NSE equity scanner CSV.

Next time, double-click **Start.cmd**. Keep the window open while using the app;
press Ctrl+C there to stop both services. On Linux x86_64, use
`bash setup-research.sh` and then `bash start-research.sh`.

Use the named ZIP above, which includes the built interface. GitHub's automatic
source ZIP requires a frontend build. The archive contains an offline
**START_HERE.html**, file-hash manifest, locked dependencies and source code.

## Included

- OpenAlgo **2.0.2.5**, Python SDK **2.0.5**, and native charts **2.3.2**.
- VectorBT backtests and Optuna optimization, the research library, automatic
  research, trial inspection, tear sheets and saved evidence.
- Saved trades on native charts with entry/exit markers, visual indicators and
  bounded replay using the original frozen candles.
- Guided first setup with unique installation keys and native broker credential
  entry. Existing configuration is preserved. Native upgrade migrations run
  before startup.
- A local launcher with readiness checks, occupied-port detection, bounded logs,
  graceful worker checkpointing and owned-process cleanup.
- Worker heartbeat writes occur periodically instead of on every cancellation
  check, reducing unnecessary disk work during optimization without changing
  financial calculations.

The Chartink Chrome extension remains optional and is installed manually from
`extensions/chartink`; ordinary CSV upload requires no extension. NautilusTrader
is optional and needs the separate Linux/WSL runtime in [NAUTILUS.md](../NAUTILUS.md).
Core installation includes VectorBT and Optuna.

## Existing installations

Stop the old app and worker. Back up `.env`, account databases, Historify prices,
strategies, and the complete research data directory. Apply the release files
without replacing those private files, then run setup. Setup preserves existing
configuration and applies repeatable migrations. Keep the same data paths.
Never copy someone else's `.env` or delete saved data to resolve an install error.

## Scope and verification

This is a public **preview** for the supported NSE cash-equity scanner workflows.
Broker history availability depends on the connected broker. Installation does
not promise profitable settings or enable automatic live position management.

Release acceptance and remaining limits are recorded in [STATUS.md](../STATUS.md).
Full Docker application setup remains separate from the tested local launcher.
