# OpenAlgo Research 0.1.0-preview.6

A clear starting path from Chartink to saved backtests and optimization studies.

## Install

Download **openalgo-research-0.1.0-preview.6.zip** from [this release](https://github.com/mamamiya7/openalgo-research/releases/tag/research-v0.1.0-preview.6), extract it, and run **Setup.cmd** on Windows x64 or `bash setup-research.sh` on Linux x86_64. Later use **Start.cmd** or `bash start-research.sh`. See the [installation guide](../RUNTIME.md).

## Start from Chartink

In **Tools → Backtest & Optimize**, choose **Import from Chartink**. The guide includes the extension download, Chrome installation steps and your OpenAlgo address ready to copy. It also appears in a setup without signals.

The separately downloadable [Chrome extension 0.1.2](https://github.com/mamamiya7/openalgo-research/releases/tag/chartink-v0.1.2) guides users through connecting OpenAlgo, opening a Chartink scanner's historical results, selecting the period, and choosing **Research in OpenAlgo**. The captured signals open a named saved setup. Review trading rules and run; prices come through OpenAlgo/Historify and the connected broker, and results stay in the Research library.

The extension is installed manually through Chrome's **Load unpacked**; it is not yet in the Chrome Web Store. It also works with Research preview.5. CSV upload requires no extension.

## Changes and compatibility

- Added the in-app installation and import guide, address copying and manual-copy fallback.
- Clarified extension connection, scanner and pending-import next steps.
- Updated README, offline guide, user guide and publishing instructions with the same journey and download links.
- Preserved the existing capture protocol, permissions, price planning, calculation engines and saved-evidence contracts.
- OpenAlgo 2.0.2.5 and the dependency locks are unchanged from preview.5.

For an existing installation, stop the app/worker and follow [updates and recovery](../DISTRIBUTION.md#updates-and-recovery). Keep `.env`, accounts, Historify prices and saved research. To update an unpacked extension, replace its files and click **Reload** at `chrome://extensions`, then refresh open Chartink tabs.
