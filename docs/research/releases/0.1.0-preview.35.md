# OpenAlgo Research 0.1.0-preview.35

12 November 2026. Local installation update; the public download remains preview.34.

This integrates OpenAlgo 2.0.3.3 plus reviewed upstream fixes through
`be6c3bbe4887a615d66eeafe9dbf3b1294f29bc0` (35 commits after our previous baseline).
The tagged platform release is `ea185f406`; the additional fixes are from main.
The calculation engines, frozen-input contracts, 408-proposal/512-account allowance,
financial validation and saved evidence remain unchanged.

## Changes useful to Research

- Fyers ordinary history now requests each chunk once at this layer (`5cbd69d72`).
  Our current native-price preparation uses this path automatically. It removes
  repeated waits for permanent errors; confirmed empty windows already skipped
  immediately in Research. Shared rate limiting and transport retries remain.
  Keep our stricter explicit-empty and candle-list checks: malformed or
  contradictory responses still fail, and a failed later chunk cannot return
  partial history as success. The legacy bounded evidence transport is unchanged.
- `/api/v1/instruments` uses the valid symbol cache with a database fallback
  (`ea90e4ffc`). Useful to API clients; this is not a demonstrated general
  Research preparation speedup.
- Charts 2.7.1 (`169bf19d2`) updates native saved-trade charts. Research report
  plots continue to use Plotly. Saved chart/feed and report tests pass.
- Broker, Socket.IO, reset-token and postback fixes are retained. Research
  account-only access survives the broker-login API-key refresh (`9d83c5de1`).
- The package installer includes the new alert-channel and password-reset-grant
  migrations; its source compatibility check requires both files.

## What does not change

The ChatGPT/Agno/LiteLLM integration and MCP gateway protection were already in
preview.34. This update contains no new decision engine or demonstrated increase
in research intelligence. Native Slack/Discord alerts can be reused for future
background completion notices, but Research does not automatically send them.
No new alert destination or live-trading permission is configured by this update.

## Verification

737 distinct targeted backend checks pass, with one optional/platform check
skipped. The initial batch exposed thirteen Fyers retry/response conflicts;
the full semantic cases were retained, guards restored, and all affected tests
rerun successfully. 188 frontend tests, TypeScript and the Vite build pass.
Upstream's Linux CI passed for the exact imported commit; this is not a fresh
Linux qualification of the custom Research package. No full scanner or fresh
optimization run is part of this host update. Installed migrations and exact
saved-result reopening are recorded in private installation receipts.
