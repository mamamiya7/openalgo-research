# OpenAlgo Research 0.1.0-preview.11

Maintenance release on OpenAlgo 2.0.2.7 with the same locked calculation libraries,
financial versions and search budgets as preview.10. Feature expansion remains
frozen. This batch includes the historical-mode and progress work qualified during
the real automatic-optimisation acceptance run.

## Changes

- Automatic research prepares a private, bounded copy of its sealed portfolio
  feature receipt once per run or resume. Trials reuse that admission while still
  checking their schedules, causal entry features, fills and portfolio limits.
  Standalone callers retain the full integrity checks. The private copy is released
  when the run returns, pauses or fails; it is not a shared cache.
- Saved artifact reads use small bounded buffers instead of requesting a 512 MB
  buffer for every small chunk. Hash, size, path and chunk-structure checks remain.
- Live progress shows committed same-window development metrics, measured pace
  and recorded check outcomes. Interim best settings remain provisional.
- Previously used dates can be explicitly admitted as **Historical optimisation —
  not independently validated**. This does not turn reused data into an independent
  final test. Strict mode now checks date admission before broker preparation.

## Qualification

The real CSV journey completed with 1,850 signals and 144 symbols: automatic
research, saved results, an exact report and a named reusable setup. It retained
the original settings because the checks did not support a reliable improvement.
All 9,028 executable daily candles matched Historify. No live orders were placed.
The acceptance run preceded this runtime patch and took 59m43s, including one
pause/install/resume. It is not the runtime of the new release.

Focused runtime equivalence, integrity, recovery and resource-ownership checks
qualify the processing changes. Measurements and their scope are recorded in
[verification](../VERIFICATION.md). No dependency, launcher or installation
procedure changed; the complete Windows/Linux matrix is not repeated for this
batch. Existing broader acceptance remains separately recorded.

## Install and update

Download the complete
[preview.11 ZIP](https://github.com/mamamiya7/openalgo-research/releases/download/research-v0.1.0-preview.11/openalgo-research-0.1.0-preview.11.zip)
and verify it against the accompanying `SHA256SUMS`. Extract everything, then run
**Setup.cmd** on Windows or **setup-research.sh** on Linux. VectorBT and Optuna are
included in setup; Nautilus remains optional. Do not download Setup.cmd alone.

For an existing installation, stop the app and research worker, back up source,
configuration, databases, Historify and research artifacts, then follow the
[update instructions](../RUNTIME.md#preserve-data-during-updates). Preserve the
existing data paths. Updated worker files and a restart are required; restarting
an older release alone does not install this patch. There are no new migrations.
