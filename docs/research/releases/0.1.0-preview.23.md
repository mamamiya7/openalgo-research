# OpenAlgo Research 0.1.0-preview.23

This frozen-feature patch fixes fixed backtest launches from saved automatic
research setups, including setups imported through the Chartink connector.
Platform, charts, dependency pins, search budgets and financial rules are unchanged.

## Correction

Switching an automatic setup to Backtest omits the search recipe. Versioned account
limits could then remain without the execution policy that the recipe normally
supplies, causing "Execution policy and risk-limit versions must match". Both the
frontend data preview and the server's saved-library launch reconstructed requests
independently, so both paths required correction.

Fixed requests now explicitly retain their implicit automatic reference policy.
The server uses the existing authoritative portfolio normalizer and copies only
its matching account limits and execution policies into the fixed request. It
retains original settings and fixed mode; it does not add a search or change saved
research. Explicit selected policies remain intact. All backend validation remains.

## Installed Chartink journey

A signed-in Chartink historical scanner opened its saved native setup through the
connector. The original rules completed a fixed backtest, were saved as a tested
setup, survived a browser reload and reopened their saved report with matching
figures. A second full run from the same original import reused cached prices;
its complete financial evidence matched exactly: native engine records, ledger,
account marks, summary, execution controls and analysis. Coverage/acquisition
identities correctly differ between downloaded and cached input preparation.
The scanner's repainting qualification and recorded broker coverage gap remain.

This larger case still exceeds one minute, including on its cached repeat. The
phase observations identify preparation before engine initialization as the main
cost; this patch fixes launch correctness and does not claim that bottleneck is
resolved. Private scanner exports, results and screenshots are not in this release.
