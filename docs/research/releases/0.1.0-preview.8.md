# OpenAlgo Research 0.1.0-preview.8

Supported preview on reviewed OpenAlgo 2.0.2.7 (`12e111465798`), native
charts 2.6.0 and OpenScript 0.8.1. Download the complete named ZIP from the
[versioned release](https://github.com/mamamiya7/openalgo-research/releases/tag/research-v0.1.0-preview.8).
The [acceptance record](../RELEASE_ACCEPTANCE_20261022.md) distinguishes runtime
qualification, actual installation tests and final documentation-only packaging.

## What changes

- Automatic VectorBT/Optuna research selects applicable stock/market conditions,
  trade timing, ATR/percentage exits, trailing rules, sizing and causal portfolio
  allocation within a fixed budget. Capital and portfolio risk limits stay fixed.
- Earlier fits are checked on later windows; costs, nearby settings, symbol/date
  sensitivity and repeat-search checks challenge improvements. The original
  setup is retained when evidence is weak. Final confirmation cannot select rules.
- Full development account histories and recipe versions are retained, verified
  on recovery and reused exactly. Saved findings, tear sheets, native trade charts,
  comparisons and named setups form one native research journey.
- Prices reuse OpenAlgo Historify and fetch missing required coverage through the
  connected broker. CSV timing and trading rules determine daily/minute needs.
- Optional risk controls are summarized on setup and remain editable. Advanced
  research controls and detailed evidence stay optional.
- Frontend dependency advisories are patched without a major-version upgrade.
  Evidence serialization has a bounded small-input optimization that preserves
  existing hashes, byte limits and large-input streaming behavior.

## Install and update

Use the complete versioned release ZIP, not GitHub's automatic source ZIP or a
single Setup.cmd file. Extract it, run Setup.cmd on Windows (setup-research.sh on
Linux), then Start.cmd (start-research.sh). Core VectorBT and Optuna install
together. Nautilus is an optional separately locked Linux/WSL runtime.

Before updating an existing installation, stop it and retain a complete backup
of source, configuration, databases, Historify and research artifacts. Restore
both old source and its matching data backup to roll back; do not run old code
against migrated data without a supported compatibility contract. See
[runtime instructions](../RUNTIME.md) and [distribution details](../DISTRIBUTION.md).

## Qualification boundaries

The v16 source has scoped numerical, service/recovery and frontend qualification,
including genuine native no-edge and positive-control programmes. The release
closure records additional package and user-journey checks separately.
Synthetic acceptance is not a fresh broker-connectivity test or a claim of
general false-discovery control, universal optimality or future profit.

Supported automatic research remains the admitted VectorBT NSE cash-equity
profile. Optional Nautilus fixed/custom calculations retain their own contracts.
Volume participation requires qualified broker/quantity provenance. More assets,
learned regime policies, live execution and a public extension-store listing are
not part of this release.
