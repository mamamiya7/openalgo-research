# OpenAlgo Research 0.1.0-preview.34

Date: 4 November 2026.

This release updates the native platform from OpenAlgo2.0.2.9 to2.0.3.2,
incorporating69 official commits through
[e2797fd3c](https://github.com/marketcalls/openalgo/commit/e2797fd3c08d3a177ed9d62cfd2698803ed4361a).
It also publishes the previously tested Research decision-loop and saved-result
fixes checkpointed in41720f3ad.

## Changes

- Retain the newer broker configuration, server-started OAuth and session
  revocation controls. Saving broker keys does not grant trading access.
- Update charts2.6.9 and locked platform dependencies, including LiteLLM1.106.6
  with its upstream import/MCP compatibility shims.
- Apply November quantity-limit, Muhurat and additive broker-key migrations.
  Keep existing configuration and saved research records.
- Review an editable research plan, explain supported setting changes, validate
  changed settings, then automatically choose/save an accepted result or save
  a precise stop reason. Funding, sizing and blocked-attempt recovery retain
  the original hard limits and native validation programme.
- Stop futile research when the fixed signals cannot produce the minimum sample.
  Reopen baseline-only reports without inventing completed optimization checks.
- Reject malformed broker-key JSON bodies with400.

## Verification and scope

582 targeted Windows backend checks passed and9 optional/platform-specific checks
were skipped.132 broker/auth/research UI checks, TypeScript and Vite passed with
the reused dependency environment and Node24.22.1. The full408-proposal/512-account
research contract is unchanged; no full scanner or new search ran for this update.

Earlier small saved-data controls and their limits remain in
[STATUS](../STATUS.md): the positive control is synthetic engineering evidence,
not proof of a real-market edge. Historical acceptance is not independent later
validation. Fresh Linux/WSL installation qualification is outside this update.

Extract the complete release ZIP. For an existing installation, stop it and
follow [updates and recovery](../DISTRIBUTION.md#updates-and-recovery). Preserve
the existing `.env`, databases, strategy files and research-data directories;
never replace them with an empty configuration. Run Setup to update the locked
environment and migrations, then Start. Enter broker keys only in the local app.
