# OpenAlgo Research 0.1.0-preview.14

A frozen-feature performance correction on OpenAlgo 2.0.2.7. Dependency locks,
financial versions, search budgets and installation steps are unchanged.

## Changes

- Publish each newly evaluated fit account and its proposal together, retaining
  immutable account shards and pre-calculation attempt reservations. Construction
  failures save the completed account for exact recovery. Other calculation
  checkpoints remain unchanged; strict quotas still apply to every new artifact.
- Encode admitted medium evidence using bounded detached JSON trees and the C
  encoder. Existing streaming behavior remains for unusual/over-bound inputs.
  Exact bytes/hashes, byte ceilings, nonfinite/cycle errors and validation remain.
  No result cache, method, screen or search-budget change was introduced.

## Qualification

75 focused checks passed, including exact saved-result/checkpoint fingerprints,
recovery without recalculation, failure injection, encoder byte/error limits and
resource ownership. Two alternating warmed native-worker comparisons used the
same actual late-search checkpoint, with isolated writes and read-only scans of
the normal store. Three new proposal observations were 5.029 →3.942s (22% less);
complete replay including verification/recovery was 14.963 →13.553s (9% less).
All final scientific checkpoint hashes matched. These are short continuation
comparisons, not a new complete-journey timing promise. See
[verification](../VERIFICATION.md#remaining-repetition-profile--22-october-2026).

No broker calls, credential access or live orders were used. No platform/setup
contracts changed, so the full installation matrix was not repeated. Frontend
assets are reused only after matching their source and asset hashes.

## Install and update

Download the complete
[preview.14 ZIP](https://github.com/mamamiya7/openalgo-research/releases/download/research-v0.1.0-preview.14/openalgo-research-0.1.0-preview.14.zip)
and verify it against `SHA256SUMS`. Extract all files and run **Setup.cmd** on
Windows or **setup-research.sh** on Linux. Do not download Setup.cmd alone.

Existing users: stop the app and worker, back up the application and data,
preserve existing data paths, update files and restart. See
[update instructions](../RUNTIME.md#preserve-data-during-updates). No new migrations.
The preceding preparation and runtime corrections are included.
