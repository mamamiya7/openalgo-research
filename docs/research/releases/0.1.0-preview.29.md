# OpenAlgo Research 0.1.0-preview.29

24 October 2026. OpenAlgo stays 2.0.2.9; pinned engines and dependencies are
unchanged. Public download links remain on the existing published preview.26.

## Behaviour

- New editable automatic runs search active-opportunity cluster allocation;
  inactive source stocks no longer reserve that mode's budget.
- A bounded native feedback programme automatically tests selected-percentage
  capital and smaller cash/risk targets when recorded constraints justify them.
- The app chooses a capacity operating point using funding and fill criteria,
  not profit, while retaining unresolved exclusions and the separate performance
  verdict. Changed accounts are never silently treated as performance-validated.
- Saved studies retain their original allocation, recipes and capital policies.
  New defaults survive both browser and server saved-setup launch paths.

The [research and contract](../AUTOMATIC_ACTIONS_20261024.md) explains the industry
sources, permitted actions, unchanged validation and remaining boundaries.
