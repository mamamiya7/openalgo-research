# OpenAlgo Research 0.1.0-preview.7

Faster checks of existing Historify prices, a patched frontend dependency, and
the same guided installation and native research workflow.

## Install

Download **openalgo-research-0.1.0-preview.7.zip** from [this release](https://github.com/mamamiya7/openalgo-research/releases/tag/research-v0.1.0-preview.7),
extract the whole archive and run **Setup.cmd** on Windows x64 or
`bash setup-research.sh` on Linux x86_64. Later use **Start.cmd** or
`bash start-research.sh`. The named asset includes the built interface;
GitHub's automatic source archives require a developer build. See
[installation](../RUNTIME.md) and [updates and recovery](../DISTRIBUTION.md#updates-and-recovery).

## Changes

- Existing-price checks share one short native connection across at most sixteen
  windows and save recovery progress once per group. Actual OHLC coverage checks,
  broker pacing, missing-window download/write/readback and frozen replay remain
  unchanged. [Measurements and limits](../HISTORIFY_CHECKS.md) distinguish local
  database and controlled-fixture timings from a complete broker-backed run.
- Axios is locked to **1.20.0**. The package workflow checks dependency advisories.
- Installation guidance explains that the complete ZIP contains the application,
  VectorBT and Optuna setup; the Chartink connector and Nautilus runtime remain
  optional. Setup/Start, broker credential onboarding and the Chartink guide are
  retained.

OpenAlgo remains **2.0.2.5**, with the same Python locks, calculation engines,
schemas and installers as preview.6. The separate Chartink extension **0.1.2**
remains compatible. Earlier release files are not overwritten.

The newer local OpenAlgo **2.0.2.6**, reusable/automatic condition-search changes
and unfinished-study **Saved trials** feature are **not in this package**.
[Their reconciliation plan](../PACKAGE_RECONCILIATION.md) preserves the public
onboarding workflow and requires separate artifact qualification.

## Verification

Runtime source is qualified by the [compatibility run for commit
318882477](https://github.com/mamamiya7/openalgo-research/actions/runs/36746646691).
This release changes version metadata, documentation and the explicit package
validation option; it does not change that runtime or its dependency locks.

The final versioned ZIP receives a separate, explicitly **package-only** run:
frontend regressions and advisory audit, rebuilt assets and manifest, Docker
build/dependency probes, and installation on fresh Windows and Linux runners.
The installation journey creates an account, runs real VectorBT and Optuna on
controlled Historify candles, replays exactly, reinstalls/restarts with retained
records, and stops owned processes. Its receipts and the checksummed ZIP identify
the accepted artifact. This run deliberately skips the already-qualified engine
matrix and is not represented as a new full runtime check.

Historical real-broker evidence covers the documented Fyers daily/minute cases.
Other brokers, the newer local development features, full Docker application
lifecycle, broad cross-version upgrades and unaided consumer acceptance remain
outside this package's acceptance. Controlled installation prices are not proof
of a live broker connection.
