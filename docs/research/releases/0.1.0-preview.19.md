# OpenAlgo Research 0.1.0-preview.19

Updates the native host **OpenAlgo 2.0.2.7 →2.0.2.9** and **charts 2.6.0 →2.6.7**,
using official main through 22 October. Includes the official release plus
subsequent native Strike Profile and dependency security fixes. Research features,
calculation pins, financial versions, search budgets and frozen evidence remain.

## Changes

Native custom chart intervals/favorites, independent study history, chart controls
and navigation; broker reliability, strategy controls and native tools. Upgrade
security dependencies in both Python and frontend locks. The full combined UI is
rebuilt; preview.17 assets are not reused. A chart aggregate timezone correction
keeps chart date labels consistent across UTC, Kolkata and New York; native daily
and minute epochs remain unchanged.

Setup now runs the upstream NSE index freeze-limit migration, preserving custom
admin values. There is no Research or Historify schema migration. Existing login,
broker configuration, native history and saved Research data remain in place.

Windows bootstrap uses built-in .NET SHA-256 and ZIP extraction so inherited
PowerShell module paths cannot hide Get-FileHash/Expand-Archive. Checksums and
stream cleanup remain enforced.

## Qualification

**193 focused backend checks and 99 frontend checks passed**, plus TypeScript and
production build. Covers history/volume evidence, archive batching, migration,
setup/dependency compatibility, saved charts/replay, native navigation and intervals.
No broker calls, orders or mode changes were used. Full Linux/Docker/every-broker
acceptance is outside this targeted host refresh.
[Full scope and upstream credits](../UPSTREAM_UPDATE_20261022.md).

## Install or update

Download the complete
[preview.19 ZIP](https://github.com/mamamiya7/openalgo-research/releases/download/research-v0.1.0-preview.19/openalgo-research-0.1.0-preview.19.zip)
and verify `SHA256SUMS`. Extract all files; run **Setup.cmd** on Windows or
**setup-research.sh** on Linux, then **Start**. Do not download Setup.cmd alone.
Existing users: stop the app/worker, back up the application/data, preserve private
settings and data paths, update files, run Setup and restart. See
[update instructions](../RUNTIME.md#preserve-data-during-updates). No Node is needed.

Thanks to OpenAlgo and its upstream contributors; original release credits are
preserved in the native 2.0.2.8/2.0.2.9 release notes and changelog.
